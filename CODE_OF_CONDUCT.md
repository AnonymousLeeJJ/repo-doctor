# Contributor Covenant Code of Conduct

## Our Pledge

We are committed to providing a friendly, safe, and welcoming environment for all contributors.

## Expected Behavior

- Be respectful and constructive
- Assume good faith
- Focus on improving the project
- Accept feedback and disagreement professionally

## Unacceptable Behavior

- Harassment or personal attacks
- Public or private intimidation
- Publishing others' private information without consent
- Other conduct reasonably considered inappropriate

## Scope

This code of conduct applies to all project spaces, including issues, pull requests, discussions, and repository maintenance activities.

## Reporting

Report unacceptable behavior through a GitHub issue marked `conduct` or contact the repository maintainer directly.
